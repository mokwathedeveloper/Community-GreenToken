# Community GreenToken Design System

This document provides a professional, aligned UX/UI design system for the Community GreenToken web application, benchmarked from modern AI-driven fintech SaaS products.

---

## 1. Purpose
The purpose of this design system is to establish a **consistent, professional, and hackathon-ready** user interface for Community GreenToken, ensuring clarity, usability, and trustworthiness while maintaining the MVP focus.

---

## 2. Typography
- **Primary Font:** Poppins, Sans-serif.
- **Headings:** Bold for H1/H2/H3, 700 weight.
- **Body Text:** Regular, 400 weight.
- **Buttons & CTAs:** Medium, 500 weight.
- **UI Consistency:** Maintain consistent font sizes, line-height, and spacing across components.

---

## 3. Color Palette
- **Primary Color:** #2ECC71 (Green, eco-focus)
- **Secondary Color:** #27AE60 (Darker Green)
- **Accent Color:** #F1C40F (Yellow for rewards/highlights)
- **Background:** #FFFFFF (Clean and modern)
- **Text:** #333333 (Readable, neutral)
- **Error:** #E74C3C
- **Success:** #2ECC71
- **Info:** #3498DB

---

## 4. Iconography
- Use **simple, flat, and consistent icons**.
- Icons should clearly indicate action or status (e.g., token, donation, leaderboard, analytics).
- Avoid cluttered or overly decorative styles.
- Maintain consistent size and stroke across the application.

---

## 5. Spacing & Layout
- Use **consistent spacing units** (8px, 16px, 24px, 32px).
- Maintain clear hierarchy: headers, subheaders, body, and UI elements.
- Cards and forms should have adequate padding for readability.
- Grid-based layout for dashboard and analytics sections.

---

## 6. Buttons & Forms
- **Buttons:** Rounded corners, clear labels, primary and secondary states.
- **Forms:** Clear input labels, placeholders, validation messages.
- **Consistency:** Button height, padding, and hover/focus states consistent.
- **CTA Placement:** Prominent on forms and landing pages.

---

## 7. Reusable UI Components
- **Cards:** For actions, tokens, leaderboard entries, and analytics metrics.
- **Modals:** For confirmations, errors, and important notifications.
- **Tables & Lists:** Responsive, sortable, with proper spacing.
- **Charts & Graphs:** Clean, simple, and color-coded for readability.
- **Toast/Notifications:** Subtle, non-intrusive feedback.

---

## 8. Design Tokens
- Maintain a **centralized token file** for colors, font sizes, spacing, and border radii.
- Tokens used across frontend and CSS/JS frameworks for consistency.
- Update tokens centrally to propagate style changes seamlessly.

---

## 9. Component Guidelines
- **Props & State:** Clearly defined, reusable, and typed.
- **Accessibility:** Ensure all components support keyboard navigation and ARIA labels.
- **Responsiveness:** Components should adapt to mobile, tablet, and desktop layouts.
- **Error/Empty States:** Provide clear, actionable messaging.
- **Icons & Labels:** Consistent usage and meaning across the application.

---

This design system ensures that **Community GreenToken maintains a professional, cohesive, and accessible UI**, allowing the frontend team and AI/Analytics interactions to implement exact, consistent designs in alignment with the MVP and hackathon objectives.
